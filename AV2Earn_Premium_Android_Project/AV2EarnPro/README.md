# AV2 Earn Android project

## Open in Android Studio
1. Extract this ZIP.
2. Android Studio > Open > choose the `AV2EarnPro` folder (the folder containing `settings.gradle`).
3. Wait for Gradle sync.
4. Build > Build Bundle(s) / APK(s) > Build APK(s).

APK output: `app/build/outputs/apk/debug/app-debug.apk`

## Important
This is a polished UI starter project. Wallet values are demo-only. Ads, tasks, games, referral tracking, database, OTP admin authentication and real withdrawal requests are not connected. Withdrawals are intended to require manual admin approval; no automatic UPI payout is implemented. Do not advertise demo balances as real earnings.
